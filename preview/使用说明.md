# 鼠标电量灯 1.1.0 预览

运行 MouseBatteryLight.exe，在顶部选择 ATK U2 Ultimate 或 MetapandaMouse，然后点击开始监控。切换前先停止监控，程序会尝试恢复原色。一次监控一个型号；本版不提供同型号多接收器选择。

首次启动默认 MetapandaMouse，每次打开只读取状态，不自动改灯。颜色阈值共用；原色备份按设备接口独立保存在 backups 文件夹，请保留该目录。更换 USB 接口可能被识别为新的设备。

MetapandaMouse 当前限定已实测读取的 F5A9 / CID 29 / MID 2。电量和 EEPROM 读取已经探测成功；颜色写入及灯效实际表现需要手动确认。其他型号不会仅因 VID 相同而放行。

请先退出旧版电量灯再运行。关闭窗口会进入托盘，退出请使用托盘菜单。
