# U2 电量灯

适用于 **ATK U2 Ultimate** 的便携式 Windows 小工具。它读取 2.4G 无线电量，并把 DPI 指示灯变成电量颜色。

## 使用

1. 将 `U2BatteryLight.exe` 放在一个可写的普通文件夹中并运行。
2. 确认鼠标处于 2.4G 模式、8K 接收器已连接。
3. 点击“开始监控”。
4. 第一次启用时，程序会自动记录原始 DPI 颜色。

默认颜色：

- 76–100%：绿色
- 16–75%：黄色
- 0–15%：红色

阈值和颜色都可以在界面中修改。程序每 45 秒读取一次电量，但只在跨越颜色区间，或颜色被 ATK HUB 覆盖时写入。

“灯效设置”支持常亮、呼吸和关闭模式，并可调节常亮亮度与呼吸速度。修改后点击“应用灯效”即可写入设备。

## 托盘与退出

- 关闭窗口默认最小化到系统托盘。
- 双击托盘图标可重新打开。
- 从托盘菜单选择“退出”才会真正结束程序。
- 默认退出时恢复原来的 DPI 颜色。

## 迁移到其他电脑

只需复制 `U2BatteryLight.exe`。程序不依赖 Node.js、ATK HUB 或额外 DLL，通常也不需要管理员权限。

设置和颜色备份保存在 EXE 同目录的 `U2BatteryLight.ini` 中。迁移到另一只鼠标时，建议只复制 EXE；程序会为目标鼠标重新记录颜色。

Windows 10/11 通常已经包含程序所需的 .NET Framework 4.x。

## 注意

- 若同时使用 ATK HUB，ATK HUB 修改 DPI 颜色后，本工具会在下次刷新时重新应用电量颜色。
- 点击“停止监控”或“恢复原色”可恢复备份颜色。
- “重录”会以当前 DPI 颜色替换旧备份；执行前应先停止监控并设置好需要保留的原色。
- 如果把程序放入 `Program Files` 等受保护目录，配置可能无法保存；建议放在桌面工具目录或其他普通文件夹。
